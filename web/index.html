What is Keyhole?

Explore the trust table →

Keyhole is a public lens on NEAR contracts. It reads the chain directly, from your browser, and tells you who can replace a contract's code, whether the code running now is the code that was verified and reviewed, and when it last changed. Every answer comes with the request that proves it.

Who can change it?

Full-access keys, upgrade methods found in the wasm call graph, and owners resolved to DAO thresholds, multisigs or ACL roles.

Is it the verified code?

NEP-330 build info, SourceScan at this exact hash, a public rebuild of the declared source, and a private AI review inside a NEAR AI Cloud TEE.

What changed?

A watcher follows every block. When code is replaced or a full-access key appears, it is on the record within seconds, and agents refuse to sign.
